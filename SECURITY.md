# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-reviewing/privately-reporting-a-security-vulnerability):
use **Security → Report a vulnerability** on this repository. Do not open a
public issue, discussion, or pull request for a vulnerability report.

Please include what you found, how to reproduce it, and any known impact.
We will acknowledge private reports and coordinate a fix and disclosure
with you.

## Scope

This policy covers this repository (`hadron-server`). Reports about other
Hadron repositories belong in those repositories, under the same private
route.
