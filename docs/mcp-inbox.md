# Team inbox: CLI and portal

The agent-team MCP inbox tools are retired by server#3082 (MCP team cut S1).
Workers use the CLI or portal. Read pending delivery with `hadron team chat inbox`;
use `hadron team chat inbox --help` for receipt and acknowledgement options.

MCP core tools remain available. An existing live worker session may attribute core
MCP calls, but worker binding and team delivery are CLI/portal operations.
